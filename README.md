# 🏋️ FitZone Gym Website

FitZone is a modern and responsive **single-page gym website** built using **HTML5, CSS3, and JavaScript**. The website is designed to provide an attractive and user-friendly experience while showcasing gym facilities, fitness services, trainers, and membership plans.

## 🚀 Features

* 🏠 Modern Hero Section
* ℹ️ Professional About Gym Section
* 🏋️ Gym Facilities Showcase
* 💪 Fitness & Training Services
* 💳 Membership Plans
* 👨‍🏫 Professional Trainers Section
* 📞 Contact Section
* 📱 Fully Responsive Design
* ✨ Smooth Scrolling & Hover Effects
* ⚡ JavaScript Interactive Buttons

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, responsive layout & animations
* **JavaScript** – Interactive functionality

## 🎯 Project Objective

The main goal of this project is to create a professional and responsive gym website that presents fitness services and membership options in a clean, modern, and engaging way.

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the FitZone Gym website.
